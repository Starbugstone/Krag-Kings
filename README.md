# Krag Kings

Design and production planning for a high-quality 3D tactical game about Krags, Nibs, scrap vehicles, boarding and persistent crew consequences.

**Current status:** design documents and concept art only. No playable build, engine benchmark, 3D production models or audio recordings have been produced yet.

Start with the [full investor POC realization plan](krag-kings-design/15-poc-realisation-plan.md). The confirmed target is a downloadable Windows depot-salvage mission, detailed modular squad customization, persistent injury/bionic recovery, music/effects/character speech, and matching concept art for the wider campaign, base and map. Unreal and Unity will be compared before engine selection.
