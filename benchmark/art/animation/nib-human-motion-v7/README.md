# Nib whole-body motion v7 — actual Blender study

The source contains coordinated captured human pelvis, spine, shoulder and arm motion, a six-second breathing/weight-shift idle, and independent ear tracks. Its 79-bone bind and 380 source mesh components are preserved. Walk is 0.8 seconds and Run 0.6 seconds; speeds and contact intervals remain tuning proposals.

Free-finger controls now specify anatomical MCP/PIP/DIP angles. They subtract the actual pre-existing bind bend instead of adding a second full curl to it. The relaxed fingers are less hooked in the inspected hand views. The original hand geometry still looks flattened and has web distortion; the following hand-fit study addresses those defects.

`full-cycle/` contains 204 actual front/side clay renders: Walk 24 frames, Run 18 frames and Idle 60 frames per view. `hand-review/` contains 18 actual palm/back/edge views. These establish rendered source geometry and poses, not final materials or engine behavior.

[Motion review video](motion-video/Nib_v7_Actual_Blender_Motion_Review.mp4): 11.6 seconds, 1280×720, 30 fps, silent. Walk repeats four times, Run four times and Idle once. The idle was rendered at 10 samples/second and those frames are held in the 30 fps container; no interpolated frames or runtime FPS claim. Source frames/contact sheets were inspected; continuous video-player review is still pending.

The face, clothing, fur and overall likeness remain unaccepted. The new hand-fit/glove sources also require integration. Neither engine imports this study yet. All sources, actual receipts, frozen executed recipes and memory records are retained.
