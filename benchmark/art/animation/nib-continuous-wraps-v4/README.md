# nib-continuous-wraps-v4

Actual saved source replaces twenty separated forearm rings with two continuous overlapping cloth strips. The strips use bounded convex slices of the actual body and fitted hand surface so they bridge the oblique skin overlap rather than shrink onto an interior hand cap. Each strip has20,848 triangles; maximum pre-offset envelope distance from skin is9.18mm left/9.92mm right. Exact79-bone bind and all seven animation curve hashes survive reopening.

Twelve actual Blender clay views cover Idle, Shoot and Run on both forearms. Inspected left-front/outer, Shoot outer and right shooting views show a substantial change from tubular rings to cloth, but regular band edges, loose strip ends and lumpy wrist flexion remain. The old right-hand shape/weapon grip is still unaccepted. Clay views do not validate materials, hair-card shadows, precise intersection clearance or runtime performance. This source was handed to the Nib restorative compatibility pass; further visual refinement remains required.
