# Character material detail candidates

Retained on 6 October 2026 for material refinement after the continuous anatomy passes. These files have not been applied to the character masters or runtime exports, and are not an approved change of clothing design or palette.

- [Brown Leather](https://polyhaven.com/a/brown_leather), Rob Tuytel: grain, creases and roughness reference for boots, belts and straps. Nominal tile size 0.4 m.
- [Denim Fabric 06](https://polyhaven.com/a/denim_fabric_06), Greg Zaal and Rico Cilliers: woven detail and worn surface reference for the existing work clothing. Nominal rounded tile size 0.3 m. It is a detail source, not a decision to make the characters wear contemporary blue jeans.

Both assets are distributed under [Poly Haven's CC0 asset license](https://polyhaven.com/license). Each directory contains unmodified 2K JPEG diffuse/albedo, OpenGL normal and roughness maps plus `source.json` with original URLs, sizes and SHA-256 hashes. Keep these originals intact. Derived character palettes, physical weave scale, dust/wear masks and portable material bakes need actual source and engine review against the concept sheets.
