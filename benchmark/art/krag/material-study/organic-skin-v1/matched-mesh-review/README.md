# Matched Krag skin study — candidate rejected

Four actual 1000-pixel Cycles CPU renders compare the current and provisional organic pigment on the same saved mesh, pose, camera and lighting. Generation exited normally with guard/native exit 0, and the rig/actions and all mesh payloads remained exact. The source was not saved or changed.

All four views were inspected. The new color produces finer grain but is too pale and uniform, and loses the localized cracked skin of the concept. This material was not adopted or baked into shared content. Neither this study nor the current source meets artistic acceptance. The generated bitmap is not measured albedo or a verified seamless texture.
