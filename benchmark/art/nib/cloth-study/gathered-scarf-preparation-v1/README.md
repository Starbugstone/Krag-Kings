# Gathered scarf — construction attribution and later plan

This is a source-based preparation record, not a generated garment.

The current actual scarf is `Nib v5 layered desert scarf`, authored by `v5_wip/nib_cloth_v5.py`. It consists of three independent112×13 radial bands. Across each band, radius increases while height falls monotonically; sine ridges change the radius but never return the material back under a fold. Solidify adds1.5 mm thickness, subdivision smooths the panels, and all vertices follow Chest. These choices explain the actual flat rigid collar and regular ledges. Noise, more subdivisions or darker fabric cannot make them gathered cloth.

Sheet02 instead shows several compressed but loose wrapping layers, irregular free edges and a low asymmetric front drape. The later replacement should retain that neck/chest footprint while authoring a continuous sheet path that turns inward and upward at the returned folds. The surface needs broad quiet cloth areas between folds, unequal fold depth and overlap, rounded fabric thickness and sewn free edges. It should not become three concentric tubes or a broad rigid cape.

Before generation, extract the actual fitted-neck/upper-chest and existing shirt/strap surfaces from the selected coherent source. Use the evaluated opened-jaw exterior as the upper clearance landmark. Keep shoulder/nape support confined to those sectors; a support projection must not lift the front cowl back into a tight collar. Fit both sides of each folded section and measure thickness/self-intersection instead of pushing every point to the nearest skin surface, which can erase returns.

The skin interface is already repaired in e1cdbd. Scarf changes must preserve that Head/Body geometry and all rig/action hashes; cloth cannot conceal an unresolved skin defect. A later Chest/Neck support field needs actual neutral, Shoot and open-mouth clearance checks. Concept-brown woven material and the retained licensed fabric scans follow only after the folded silhouette passes. Krag's returned-section helper is a useful construction reference, but its species dimensions and unaccepted result are not an approved Nib garment.

Required actual evidence: Front, Profile and Back, then Shoot and tongue/open-mouth clearance, with enough neutral light to see overlap and material thickness. No new scarf dimensions or design canon are approved by this record.
