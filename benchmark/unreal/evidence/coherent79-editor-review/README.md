# Coherent79 Nib: actual Unreal material review

The running Unreal 5.8.3 editor game mode saved all nine 1920 × 1080 views and exited normally with the fresh completion marker. All nine images were inspected. This is actual engine rendering of the newly imported Nib; it is not standalone package, movement, performance or artistic acceptance evidence.

The pose and scene were held fixed across Generic Subsurface, Default Lit and Subsurface Profile modes. Actual screen percentage was 100, Substrate 0, SSS Scale 1, SSS Quality 1 and Burley Quality 1. The exact native report, images, executed source/configuration, material plan and shared-source snapshot are preserved with hashes in `artifact-receipt.json`.

Profile and Default Lit retain more local contrast than Generic, which visibly washes skin. The new Nib face, mottling, ears, clothing and masked hair render without a missing-material failure. Ear/head coverage is still sparse and broken, the cowl has angular jagged edges, and shaded facial/ear regions are very dark. These are unresolved visible defects, also apparent in the current Unity candidate; their cause has not been isolated to geometry, alpha mip coverage or lighting. The Krag still uses the older shared v7 assets and fails anatomy/likeness review. Profile is the next technical rendering candidate, not an approved final appearance.

All images are frozen idle-pose comparisons. They do not validate the new whole-body clips, six-second idle, ear acting, action overlap or natural transition quality. Those require the subsequent packaged runtime checks.
