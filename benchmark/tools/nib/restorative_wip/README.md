# Restorative compatibility and socket fit

The compatibility and socket recipes have now generated isolated sources and
actual three-view evidence. Both remain artistically unaccepted and separate
from shared FBXs. See `art/nib/restorative-study/coherent-v1/actual-result.json`
and `socket-wrist-v1/actual-result.json`. The original preparation below records
its intended preservation scope; the actual receipts establish execution.

`build_restorative_compatibility.py` will:

- Require the exact input hash, semantic Natural Body/fuzz payloads and current
  migrated 79-bone bind/action contract.
- Carry the original licensed left-forearm face set 12 through the same two
  subdivision levels. Actual point and face correspondence must match before
  creating a Grip-only Body and fine-fuzz subset. The existing legacy Grip
  surfaces are retained in a hidden collection outside the export collection.
- Copy retained point/morph coordinates, UV corners, material assignments and
  weights explicitly. The Natural torso/arms, hands and glove remain untouched.
- Refit the existing twelve metal finger segments, twelve hinges and two thumb
  segments onto the existing anatomical left-digit joints. Segment lengths
  follow ordinary finger reach; joint radii/materials/UVs remain. The original
  Hand-weighted thumb becomes two ordinary Thumb1/2 segments. No bone or action
  changes, no strength/aiming/tool upgrade.
- Save and reopen an isolated source and verify all seven canonical clips,
  every action hash, the complete bind and unrelated meshes.

`audit_saved_rest_frames.py` has actually run using standalone bundled Python.
All fourteen original segment definitions match the recorded old rest frames:
maximum head error 0.093 micrometres, axis error 0.024 micrometres. This does not
prove native metal geometry, cuff fit or posed contact; those gates execute in
the builder and actual three-view review. `review_restorative_compatibility.py`
prepares ArmNeutral, HandCurl and Shoot views. The executed jobs are `generate-coherent-v1.job.json` and
`review-coherent-v1.job.json`. The first actual assembly exposed a disconnected
wrist and intersecting cuff. `build_socket_wrist.py` and its two socket job
recipes correct those interfaces against the actual skin boundary, preserving
every original mesh and the complete bind/action contract.

The separate wrist audit on the actual semantic Body finds two closed,
104-vertex oblique wrist boundaries. Root identified a lateral natural-hand
cuff mismatch and owns that correction plus union-supported cloth wraps.
This pass must not independently rebuild those hands or use an older input.

Remaining axillary stretch, neutral shirt contact and full concept-likeness
failures remain explicit. This compatibility work cannot establish artistic
acceptance. Right-hand anatomy/grip migration remains root-owned afterward.
