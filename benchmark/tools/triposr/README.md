# Isolated TripoSR reference pilot

This is a parent-authorized local experiment to assess whether image-derived geometry is useful as a sculpt/reference donor. It does not replace character art acceptance, the authored rig, or facial/limb topology. The network-only download has completed with official hash checks; environment resolution, installation and inference have not run.

`download_only.py` consumes the pinned `network-download-plan.json`, streams public model/source/wheel files into `benchmark/local/triposr-downloads-v1` at at most 8 MiB/s, checks official model/wheel/config hashes, and records immutable-commit source-archive hashes. It does not extract or execute downloaded content, install packages, compile extensions, import Torch, touch the GPU, or change existing environments. This network-only stage may overlap art jobs with root's explicit authorization.

`resolve_environment.py` and `resolve-environment.job.json` are **prepared, not executed**. They create a separate Windows Python3.10 venv/cache, install only pinned pip/setuptools/wheel bootstrap tools there, and obtain a dependency resolution report/hashed lock/license inventory. OmegaConf requires the pinned117KB pure-Python antlr4 4.9.3 source distribution; all other dependencies must resolve as wheels. Its original archive hash is checked, and metadata is evaluated with the pinned bootstrap backend under the guarded job. This preparation is not yet a resolved installation. Bulk installation, native compilation and inference require their own granted resource boundary. Use the existing VS2022 toolchain for a separately pinned CPU-only `torchmcubes` extension rather than installing a global CUDA Toolkit.

The official TripoSR source/model are MIT. The chosen historical `torchmcubes` commit is MIT according to that commit's README/setup metadata; current master has different terms. PyTorch and each resolved transitive package must retain their actual license notices. Exact revisions and original license URLs are in the plan. Do not upload concept images; eventual input will be a preserved-sheet crop, evaluated locally. No global PATH, GPU driver, Blender, Unreal or existing Python environment changes are authorized by these scripts.
