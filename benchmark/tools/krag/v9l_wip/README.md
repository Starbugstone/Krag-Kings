# Krag v9l facial-plane and ocular study

Prepared against the hash-pinned v9ka mouth source; no v9l source or render exists yet. The first actual side view must precede the rest of the views. This is a concept-likeness correction, not extra crack texture.

The old ungenerated relief helper excluded whole orbital face sets, suppressing most of the intended brow. This recipe instead protects the actual ocular opening and mouth rim while shaping a lower broad brow, separated glabellar furrows, angular zygomatic/cheek planes and a broad mandible. It retains the measured whole-head proportions and bounds forward displacement to avoid the previous narrow profile beaks.

The real curved iris components receive retained source-coordinate radial amber pigment and a dark limbus. The existing curved optical shell receives a wet corneal coat. No new transparency layer or flat eye card is introduced. These attributes require baking on the actual Face UV atlas before runtime export; coat response needs explicit engine integration.

Body anatomy/bind/actions and shared assets stay unchanged. Source and actual HeadSide/Head/Front/Blink/OpenMouth views remain required before any acceptance or export.
