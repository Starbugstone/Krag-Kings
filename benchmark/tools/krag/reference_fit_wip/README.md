# Visible reference masses on the existing Krag topology

This is a **prepared, ungenerated** source candidate. The external GLB is a reviewed but unaccepted concept-derived reference at `benchmark/unreal/evidence/triposr-krag-bust-matted-v2/Krag_Bust_Reference.glb`, SHA256 `f6513fa6cb0c50c07d9e1adad1a17e7c15a1f75bfa8dc0745593cb08ef5f0026`. Its raw units are normalized and Z-up; the exact display/camera contract is retained beside it. It does not supply a new canonical head, unseen surfaces, eye/mouth topology, teeth or skin detail.

`reference_landmarks.py` reconstructs selected visible points from the actual quarter-camera image and raw mesh. `fit_visible_masses.py` aligns their relative masses to the authored eyes and integrates a smooth spatial field through the existing Head/Face/MouthInterior topology. The input-visible near-side masses supply bilateral broad fitting targets; the less reliable reverse side is excluded. Actual ocular globe/contact coordinates remain fixed. Cached preflight now has 28.35 mm maximum change and no flipped triangles; the failed direct and overstrong variants remain explicitly recorded under `art/krag/reference-fit-study`.

`commissure_support.py` addresses a separately measured saved-source defect: the old lower-rim square-root weight has an infinite slope at each real mouth corner. A 14 mm geodesic smooth factor retains full support away from the corners and keeps upper lip/nose on Head. This is a proposal awaiting actual opening inspection, not an accepted mouth.

`build_visible_masses_v9q.py` starts from pinned actual v9p, preserves all bind matrices/action curves/unrelated geometry, saves compressed and reopens before declaring source construction complete. The review jobs cover matched frontal clay, unobstructed right clay, material portrait and full-range front/right opening. Generation and actual visual inspection have not run yet. Existing hooked tusks, materials, cowl and mechanical-jaw compatibility remain unaccepted.
