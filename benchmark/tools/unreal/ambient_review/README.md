# Prepared sand-bounce comparison

This is an unexecuted lighting-only study. Package `6926aba6…` and its nine actual material views remain unchanged. The added native path has not compiled or run yet.

The coherent79 review's actual diagnostics report an active movable, real-time captured Sky Light at intensity0.85, a solid black lower hemisphere, Lumen diffuse indirect/radiosity enabled, and a1.52km terrain mesh represented by one Lumen card and an18³ distance-field grid. These support a ground-bounce/coverage investigation; they do not prove the cause of every dark area.

The prepared path keeps Profile skin, source geometry, frozen idle pose, cameras, manual exposure, upper sky and the55klux neutral sun fixed. It replaces only the lower-hemisphere color with0%,12.5% and25% of a bounded flat-Lambertian sand estimate. Existing captured lighting is reused; no additional light actors, material samples or per-frame simulation are added. It remains an approximate distant fill, not a measured GI replacement or a claim of zero performance cost.

`prepare.py` has read the existing2048² sand BaseColor with no edits or model/engine initialization. Its mean decoded linearRGB is(0.435385,0.285607,0.136966). Multiplying by55,000×sin(42°)/π gives the unscaledRGB radiance estimate(5100.312,3345.748,1604.491). The actual tested lower colors will be12.5% or25% of those values before the retained0.85 Skylight intensity. The texture is an authored appearance input, not measured spectral reflectance; the fractions are explicit provisional tuning. Exact texture/code hashes and command arguments are in `plans/sand-bounce-coherent79-v1`.

The installed5.8 shader `ReflectionEnvironmentShaders.usf::ApplyLowerHemisphereColorPS` applies the color only where cubemap directionZ<0, multiplied by capture pre-exposure. `USkyLightComponent::SetLowerHemisphereColor` updates the movable light's render state. [Epic's Sky Light documentation](https://dev.epicgames.com/documentation/unreal-engine/sky-lights-in-unreal-engine) describes real-time capture and lower-hemisphere controls; the installed component header explicitly identifies approximating sky bounce as a use of the hemisphere option. This study keeps the hemisphere solid and changes its warm low-energy radiance.

Any chosen candidate needs separate packaged verification and timing under the shipped settings. No new performance result or artistic acceptance exists yet.
